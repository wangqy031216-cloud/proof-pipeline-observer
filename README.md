Lean 定理证明转译过程的只读可视化存档：helper DAG、局部 Lean 探测、失败修复、上下文压缩与验收状态，支持时间轴回放（拖动滑条或直接分享带 `?at=` 的链接回到任意历史时刻）。

本站为**冻结快照**（静态导出于 2026-10-27），不含任何后端调用；数据已脱敏（内部路径、进程号已移除）。顶部下拉可切换各次运行。页面由 [proof-trace 纯函数模块](proof-trace.js) 对记录事件做确定性重放，不补造任何未记录的状态。

生成方式：观察器（只读）→ 发布网关（白名单 + 清洗）→ `export_static.py` 冻结导出。

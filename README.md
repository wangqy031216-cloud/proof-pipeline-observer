# 证明流水线 · 静态观察存档

Lean 定理证明转译过程的只读可视化存档：helper DAG、局部 Lean 探测、失败修复、上下文压缩与验收状态，支持时间轴回放（拖动滑条或分享带 `?at=` 的链接回到任意历史时刻）。

本站为**冻结快照**（静态导出），不含任何后端调用；数据已脱敏（内部路径、进程号已移除）。页面由 [proof-trace 纯函数模块](proof-trace.js) 对记录事件做确定性重放，不补造任何未记录的状态。

## 展示的代表性轨迹

标题前缀标明该轨迹覆盖的流水线口径：

| 前缀 | 含义 |
|---|---|
| **[全过程]** | unified 全流程：主声明转译（检索/草稿/编译/语义审核/锁定）→ DAG 证明 → 独立 Kernel / 确切导出 / 独立重放 |
| **[仅定理转译·已停止]** | 只运行到主声明转译阶段，之后被主动停止 |
| **[仅DAG证明·给定声明]** | 跳过主声明转译（benchmark 已给形式声明），只做证明转译 |
| **[仅DAG证明·给定Lean]** | 同上，输入为数据集给定的 Lean 声明 |

当前收录四条：**FCS76**（全过程样板，22 节点 / 1972 事件）、**98 主声明转译**（仅定理转译后停止）与 **98 给定Lean**（同一题的配对运行：错误的自然语言入口被停止 vs 给定 Lean 直接证明）、**历史143**（给定声明的丰富证明轨迹，7 节点 / 602 事件 / 45 次压缩）。

生成方式：观察器（只读）→ 发布网关（白名单 + 清洗）→ 冻结导出。
